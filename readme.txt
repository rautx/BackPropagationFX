1. COMO EXECUTAR O PROGRAMA
Pre-requisito: JDK 21 instalado com variavel JAVA_HOME configurada.

Opcao A (IntelliJ IDEA):
1. Abra a pasta do projeto pelo arquivo pom.xml (Open as Project).
2. Aguarde o download das dependencias.
3. Execute o arquivo Launcher.java (src/main/java/com/example/backpropagationfx/Launcher.java).

Opcao B (Linha de comando no Windows):
Abra a pasta do projeto no CMD ou PowerShell e execute:
  .\mvnw.cmd clean compile
  .\mvnw.cmd javafx:run

Opcao C (Linha de comando no Linux/macOS):
  ./mvnw clean compile
  ./mvnw javafx:run
